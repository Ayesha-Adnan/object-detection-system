# Object Detection System 🎯

**Live Demo:** [https://ayesha-adnan.github.io/object-detection-system](https://ayesha-adnan.github.io/object-detection-system)

A real-time Object Detection web application built using **TensorFlow.js** and **COCO-SSD model**.

## ✨ Features
- **Real-time Camera Detection**
- **Image Upload Detection**  
- **80+ Objects Detection**
- **100% Browser Based**

## 🛠️ Tech Stack
HTML, CSS, JavaScript, TensorFlow.js

## 📸 How to Use
1. Open Live Demo link
2. Click **"Start Camera"** for live detection
3. Or click **"Upload Image"** to detect objects
